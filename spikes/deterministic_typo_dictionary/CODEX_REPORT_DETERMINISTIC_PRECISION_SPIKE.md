# Deterministic sequence / typo dictionary precision spike

## Scope and method

This is an isolated Python prototype under `spikes/deterministic_typo_dictionary/`.
It has no imports from, or changes to, service code.  The tested v1 scope is
limited to calendar, SDLC/deployment/priority, workflow/status, sizing,
business titles/status, and list markers.  Traditional calendars, ranks,
music, astronomy, directions, and other deferred categories are absent.

Run command:

```powershell
python spikes/deterministic_typo_dictionary/spike.py
```

The implementation applies the requested gates as follows.

| Tier | Experimental rule |
| --- | --- |
| Tier 1 | Multi-syllable mapped typo, exact token boundary, global match. URL, inline-code, placeholder, and tag spans are excluded. |
| Tier 2 | Short/ambiguous mapping only in one delimiter-separated line (comma, slash, middle-dot, or parentheses); two or more anchors from the same category must occur in non-reversed declared order. |
| Tier 3 | Recognize only line-start circled markers or dotted Hangul/Roman markers; flag duplicate/skipped progression at low confidence with no correction. |

`dictionary.json` is a readable, Korean-only experimental dataset. It is
not a production schema or service asset.

## Corpus

The corpus is newly authored Korean business/technical text in
`corpus.json`.

| Set | Cases | Composition |
| --- | ---: | --- |
| Seeded true positives | 18 | 3 per tested category, including 3 Tier-3 marker anomalies |
| False-positive traps | 18 | 3 per category; includes prose uses such as `화`, `수정`, `가장`, `상담`, `II형`, and inline `①번` |
| Clean paragraphs | 5 | General business/technical paragraphs unrelated to the categories |

The result counts one seeded expected token as a true positive only if it is
flagged by its assigned category. Any flag in a trap or clean paragraph is a
false positive. Precision is `true-positive flags / all flags`; recall is
`detected seeded tokens / expected seeded tokens`.

## False-positive record

No false positives were emitted: **0** across all 18 false-positive traps
and all 5 clean paragraphs. Therefore there are no false-positive cases or
causes to enumerate for this corpus run.

The Tier-2 traps specifically produced no flags because none supplied both
a delimiter-separated list block and two same-category anchors. The Tier-3
prose traps produced no flags because none were a multi-line, line-start
marker progression.
